## Описание проекта 
E-commerce  — электронная торговля, или электронная коммерция.  
На данном этапе работы мы не будем реализовывать систему платежей, однако подготовим всё для того, чтобы у нас появилось ядро для интернет-магазина. 

## Использование
Пока немного - только класс товаров (product) и категорий товаров (category)

## Установка
Склонируйте репозиторий

## Разработка
Проект только начат, надеюсь закончить  
Реализован метод add_product  
Атрибут списка товаров Category сделан приватным  
Для него реализован getter    
Реализован класс-метод new_product() с помощью декоратора @classmethod  
Атрибут «цена» класса Product имеет приватный режим доступа  
Для атрибута «цена» реализован getter  
Для атрибута «цена» реализован setter с проверкой значения цены > 0
